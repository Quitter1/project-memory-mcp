# 部署指南

## 推荐部署模式

单宿主机部署（当前推荐）：

- Qdrant
- embedding_server (BGE-M3)
- project-memory-mcp (MCP stdio)
- Claude Code / Agent

都运行在同一台内网机器上。

SQLite 不支持多机器并发写入；跨机器部署需迁移 PostgreSQL（后续版本）。

## 目录建议

```
F:\project\project-memory-mcp        # 项目代码
F:\project\embedding_server         # BGE-M3 embedding 服务
F:\project\project-memory-data      # 数据目录（可选）
F:\project\project-memory-backup    # 备份目录（可选）
```

## 服务组件

| 组件 | 作用 |
|------|------|
| Qdrant | 向量索引 |
| embedding_server | BGE-M3 文本向量服务 |
| project-memory-mcp | MCP 工具服务 |
| SQLite memory.db | 事实源 |
| logs/ | 运行日志 |
| reviews/ | 审阅包 |

## 端口

| 服务 | 端口 |
|------|------|
| Qdrant HTTP | 6333 |
| Qdrant gRPC | 6334 |
| embedding_server | 8008 |
| MCP | stdio（无 HTTP 端口） |

## 启动顺序

1. 启动 Qdrant
2. 启动 embedding_server
3. `python scripts/check_embedding.py` 确认可用
4. `python scripts/check_qdrant.py` 确认 collection
5. `powershell -File scripts/kill_mcp_processes.ps1 -Kill` 清理旧进程
6. 打开 Claude Code

## 安全建议

- Qdrant 不建议暴露公网（监听 127.0.0.1）
- embedding_server 不建议监听 0.0.0.0
- API Key 只通过环境变量，不写入配置文件
- memory.db 要定期备份
- 日志定期检查，异常及时排查

## 备份

```bash
python scripts/ops/backup_memory_db.ps1
```

备份内容：memory.db、projects.yml、server.yml。

不备份：logs、reviews、.env、API Key。
