# 正式使用检查清单

## 每次启动前

- [ ] Qdrant 运行中（check_qdrant OK）
- [ ] embedding_server 运行中（check_embedding OK）
- [ ] diagnose 全部检查通过
- [ ] eval_search hybrid 可命中
- [ ] 旧 MCP 进程已清理（kill_mcp_processes.ps1 -Kill）
- [ ] Claude Code 重新打开

## 每周维护

- [ ] 备份 memory.db（backup_memory_db.ps1）
- [ ] 运行 eval_search 确认检索质量
- [ ] 查看 errors.log 有无异常
- [ ] 清理 rejected 测试知识（cleanup_test_memories.py --dry-run）
- [ ] 查看 pending_review 并审核（review_memories.py list）

## 每次升级后

- [ ] pytest tests/ 全部通过
- [ ] health_check.ps1 全部通过
- [ ] kill old MCP 进程
- [ ] 重新打开 Claude Code
- [ ] 手动搜索验证
- [ ] 检查 logs 无异常

## API Key 安全

- [ ] SK 只用环境变量
- [ ] SK 不进配置文件（server.yml、.env 提交版）
- [ ] SK 不进日志
- [ ] SK 不进 audit_log
- [ ] SK 不进 review pack
- [ ] 测试后吊销测试 SK
